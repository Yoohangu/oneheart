① 구글 캘린더 연결 설정 (처음 한 번만)

이 페이지가 목사님의 구글 캘린더를 읽고 쓰려면 구글에서 발급하는 클라이언트 ID가 필요합니다. 컴퓨터에서 아래 순서대로 한 번만 진행해 주세요.

  1. Google Cloud 콘솔에서 새 프로젝트를 만듭니다. (이름 예: ministry-calendar)
  2. Google Calendar API 페이지에서 사용을 누릅니다.
  3. Google 인증 플랫폼에서 시작하기 → 앱 이름·이메일 입력 → 대상 외부 선택 → 만들기.
  4. 같은 화면 왼쪽 대상 메뉴 → 테스트 사용자에 목사님 구글 계정(Gmail 주소)을 추가합니다.
  5. 왼쪽 클라이언트 메뉴 → 클라이언트 만들기 → 유형 웹 애플리케이션을 고르고 아래 두 주소를 넣습니다.

구글 캘린더에 연결하기

연결하면 구글 캘린더의 일정이 그대로 보이고, 여기서 추가·수정한 일정도 구글 캘린더에 바로 저장됩니다. Notion Calendar와 아이폰 캘린더에도 자동으로 반영됩니다.

처음 연결할 때 “Google에서 확인하지 않은 앱” 화면이 나오면 고급 → (앱 이름)(으)로 이동을 누르고 캘린더 권한을 모두 허용해 주세요. 보안을 위해 연결은 약 1시간마다 자동으로 갱신됩니다.
